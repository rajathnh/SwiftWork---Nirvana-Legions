# SwitfWork---Nirvana-Legions

Landing Page:
Overview of the platform with links to login, sign up, and basic features.

Authentication Pages: - Backend Done, upgrades - Email verification on first login
Sign Up: Separate forms for freelancers and clients.
Login: Common login page for all users.

Freelancer Profile Page: - Backend Partially Done, Image Update, Review show left
Displays freelancer details: skills, experience, portfolio, and reviews.

Client Profile Page:Backend Partially done, Order list left
Shows client details: previous job listings and reviews (if any).

Freelancer Dashboard:
Lists available job postings that match the freelancer’s skills.
Option to view details and place bids.

Client Dashboard:
Displays bids received for their job postings.
Option to create new job postings.

Job Details Page:
Accessible to freelancers.
Detailed job description, budget, required skills, and the ability to place a bid.

Order Interaction Page:
Shared workspace for a freelancer and client once an order is accepted.
Includes messaging and file-sharing functionality.

Payment Page:
Allows clients to process payments for accepted jobs.
